# 🚀 Spring AI Roadmap (2026)

> A complete roadmap to become a **Spring AI Developer** using **Java**, **Spring Boot**, **LLMs**, **RAG**, **Agents**, and **MCP**.

# 📚 Prerequisites

Before learning Spring AI, make sure you are comfortable with:

- ✅ Core Java (Java 17+)
- ✅ OOP Principles
- ✅ Collections Framework
- ✅ Exception Handling
- ✅ Multithreading Basics
- ✅ Maven/Gradle
- ✅ Spring Framework
- ✅ Spring Boot
- ✅ REST APIs
- ✅ Spring Data JPA
- ✅ PostgreSQL/MySQL
- ✅ JSON
- ✅ HTTP Protocol
- ✅ Git & GitHub
